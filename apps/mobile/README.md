# Golden Starter V3 — Mobile Core App (Expo SDK 57)

Cliente móvil construido con Expo SDK 57, React Native 0.86, motor Hermes y navegación con Expo Router.
Incluye soporte para sincronización offline tolerante a desconexión mediante SQLite y outbox con deduplicación por UUIDv4 en servidor.

Las versiones deben validarse con `npx expo-doctor` y pruebas de compilación antes de certificar cambios mayores.
