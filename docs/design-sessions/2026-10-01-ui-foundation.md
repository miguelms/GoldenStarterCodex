## Decisiones confirmadas por el usuario

1. **Dirección visual:** Base UI3 es la alternativa ganadora; la propuesta exacta v1 quedó aprobada el 2026-10-01.
2. **Tema:** usar preferencia del sistema al inicio y recordar el cambio manual.
3. **Primitivas:** Base UI bajo wrappers estilo Shadcn.
4. **Cierre:** Dialog cierra con Escape y clic fuera. AlertDialog requiere Cancelar o una acción y no cierra con clic fuera.
5. **Badges:** `default`, `secondary`, `outline`, `destructive`, `success`, `warning` e `info`.
6. **Alcance funcional:** la spec FEAT-002 recibió aprobación del usuario; esta decisión no aprueba el diseño visual ni habilita por sí sola el frontend.

Se documentaron además colores y estados de secondary, accent, destructive, success, warning, info, invalid, disabled, borders, menú y badges en la spec y en el reporte enlazado. El par inicial `muted-foreground #686960` sobre `muted #E8E4DB` dio 4.38:1, así que se corrigió el candidato a `#62635A` (4.80:1). El overlay oscuro inicial al 62% dejaba el texto principal del backdrop a 2.87:1; se corrigió a 45% (ratio compuesto 5.03:1 sobre el fondo de página y 4.85:1 sobre card). Texto muted subyacente al overlay queda bajo 4.5:1, registrado explícitamente como contenido de fondo inactivo por el modal.
