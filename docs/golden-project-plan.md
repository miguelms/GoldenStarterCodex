# Plan de gobernanza de GoldenStarterCodex

GoldenStarterCodex evoluciona como una fuente de gobernanza versionada para aplicaciones compuestas. El stack técnico se desarrolla y publica por separado.

## Fases

1. Mantener perfiles, skills, MCP y ciclo SDD/TDD coherentes.
2. Publicar el contrato de composición y lockfile entre gobernanza y stack.
3. Crear un compositor reproducible con revisión de ownership y diffs.
4. Validar la composición con GoldenStarterWebIA.
5. Reutilizar la misma gobernanza con GoldenStarterWebCore, GoldenStarterMobileCore y GoldenStarterMobileIA.

Una fase solo se completa cuando tiene contrato, evidencia y revisión del usuario.
