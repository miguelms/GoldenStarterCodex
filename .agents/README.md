# Skills del proyecto

Este directorio contiene skills en formato Agent Skills, ubicadas en `.agents/skills/<nombre>/SKILL.md`. Cada skill documenta un flujo reutilizable que Codex carga cuando la tarea lo requiere.

Los perfiles de subagentes Codex viven por separado en `.codex/agents/*.toml`. El registro de responsabilidades y handoffs está en [`docs/agent-registry.md`](../docs/agent-registry.md).
